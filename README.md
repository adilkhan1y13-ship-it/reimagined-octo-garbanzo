# Last Zone 3D — browser prototype

An original lightweight 3D third-person arena shooter prototype using Three.js. It has enemy bots, a basic auto-aim assist that aims at bot heads, firing, health, kills, a safe-zone ring, and mobile joystick/fire controls.

## Run
- Internet connection is required because Three.js is loaded from jsDelivr CDN.
- Extract the ZIP and host the folder on a static host, or use a local development server. Some mobile browsers block ES modules when opening `index.html` directly from file storage.
- Open `index.html` in Chrome and tap **START MATCH**.

## Controls
- PC: WASD/arrow keys, Shift to sprint, click to fire.
- Mobile: left joystick and FIRE button.

This is a prototype, not a complete commercial game. It is an original project, not a copy of Free Fire and does not connect to or modify Free Fire.
